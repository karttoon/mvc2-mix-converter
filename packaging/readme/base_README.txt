Your stock game files go here. You don't need to copy anything by hand -
open MixConverter.exe and use the "1. Setup" tab.

After setup this folder will contain:
  stock_game_50.arc     a clean copy of your Steam game data
  stock_music\          a clean copy of your Steam music (.sngw)
  MVC2_STOCK_DC.cdi      (optional) a stock Dreamcast disc, only needed
                         if you want to BUILD Dreamcast discs.

These come from the game you already own; nothing is shipped with the tool.
